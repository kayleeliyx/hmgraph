# P01-20240202-110250: All 78 Single-Video Questions

## Final experiment

All 78 HD-EPIC VQA questions whose inputs contain only
`P01-20240202-110250` were answered using W only, grouped L1 only, and W+L1.

Retrieval used question/choice text, input time bounds, and TF-IDF ranking. For
localization questions, evidence around every candidate interval was supplied.
The final run used Qwen2.5-7B-Instruct in bfloat16 on GPU. Each A–E option was
scored directly at the answer position, avoiding generation parsing failures.
Ground truth was used only after prediction for scoring.

## Overall result

| Evidence | Correct | Accuracy |
|---|---:|---:|
| W | 23/78 | 29.5% |
| L1 | 26/78 | 33.3% |
| W + L1 | 22/78 | 28.2% |

The five-choice random baseline is 20%. L1 is the strongest condition. At
least one condition answered 32/78 questions correctly, and all conditions
selected the same answer on 46/78 questions.

## Interpretation

- L1 is strongest overall, reaching 33.3% and 13/28 on action recognition.
- W retains useful attributes, but its extra detail does not improve the
  current generic prompt consistently.
- Concatenating W and L1 does not help. W+L1 needs hierarchical retrieval, not
  a simple union of redundant evidence.
- Action localization is unexpectedly weak at 6–7/36. Generic TF-IDF retrieval
  and the answer prompt are not reliably comparing candidate intervals.
- BBOX identity, persistent object state, precise “how,” and “why” remain
  structurally weak or absent in grouped L1.
